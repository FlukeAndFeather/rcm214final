# Data for Analysis of Stream Water Concentrations in Bisley, Puetro Rico Streams Before and After Hurricane Hugo

### Data Sets Used
Data sets from four sites were selected to replicate the analysis done for Figure 3 from Schaefer et al. (2000), displaying the concentration of five different ions in Bisley, Puetro Rico streams before and after Hurricane Hugo. The data sets were sourced from [EDI Data Portal](https://portal.edirepository.org/nis/mapbrowse?packageid=knb-lter-luq.20.4923064) and are as follows:

RioMameyesPuenteRoto.csv : This file contains data from the Puente Roto Mameyes Watershed (PRM)

QuebradaCuenca1-Bisley.csv : This file contains data from the Bisley Quedabra 1 Watershed (BQ1)

QuebradaCuenca2-Bisley.csv : This file contains data from the Bisley Quedabra 2 Watershed (BQ2)

QuebradaCuenca3-Bisley.csv : This file contains data from the Bisley Quedabra 3 Watershed (BQ3)

### Columns
Each data set features columns for Sample ID, Code (with a numerical identifier for each row), Sample Date and Time, various environmental conditions, and the concentrations of different ions. For the analysis, only the columns Sample ID, Sample Date, K, Mg, Ca, NH4-N, and NO3-N were used.
